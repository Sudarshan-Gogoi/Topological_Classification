# Topological_Classification: Data, Scripts, and Tutorials
Available for the categorization and prediction of cancer subtypes and the identification of cancer-associated genes.
Supplementary Tables 1 and 2 in the 'Data Files' list the topological features and cancer‑associated genes that were identified using TDA‑based cancer subtype categorization and prediction models, as described in the paper "Topological Mapping of Single‑Cell Transcriptomes Reveals Hidden Cancer Drivers" by S. Gogoi et al.
